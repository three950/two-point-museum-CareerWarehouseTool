# 双点博物馆tool：生涯展品仓库

当前版本：0.1.13 。

⚠本工具非官方，安装风险自负⚠。免费发布，禁止任何未经授权的商业销售。  

- 本工具由仓库作者在**个人环境**下开发并自用，仅验证过以下环境：  
  - 游戏平台：Steam  
  - 游戏版本：12.0.244870（2026-10-09.1815 构建）  
  - 系统：Windows11 x64
- **其他平台（Epic / Xbox / Microsoft Store）、其他游戏版本、其他系统环境均未测试，不保证可用。**
- 工具行为依赖 IL2CPP 元数据 v31；游戏更新后元数据变化可能导致功能失效。

## 安装教程

1. 退出游戏，双击 `CareerWarehouseTool-v0.1.13.exe`。
2. 选择包含 `TPM.exe` 的游戏目录，点击“一键植入”。
3. 自动备份：每次植入都会先备份当前游戏的生涯和沙盒存档，保存在游戏目录下的 `CareerWarehouse/backups/时间戳/saves-before-install.zip`。

## 功能说明

1. 默认博物馆五星后才开启生涯展品仓库功能，可在设置滚动到“游戏”的最后，在“生涯仓库 · 开启条件”中点击“本馆五星后开启”“关闭”或“开启”。设置立即生效。
2. 功能开启时，原“库存”按钮右侧新增生涯展品仓库图标。关闭时图标不会出现。
3. 生涯展品仓库里的展品品质取贴纸图鉴里记录的历史最高记录，组合展品会直接以完整的形态出现。

## 卸载与更新

1.退出游戏，在工具中点击“卸载功能”，移除本工具的加载 DLL。不会卸载已有实物展品、游戏存档和备份。
2.游戏更新后若功能出现问题，请退出游戏并重新运行“一键植入”，工具会重新检测并生成地址映射。

## 0.1.2 改动说明

- 虚拟目录原先使用待入库记录分支，原版会隐藏实例的知识、品质等区域。新版本显式填充知识文本、品质图标和稀有度图标，并重新启用对应区域。

## 0.1.5 改动说明

移除完整游戏文件哈希的安装硬限制，以及加载模块中的固定版本和地址。安装器生成 `CareerWarehouse/runtime-bindings.bin`，保存自动定位结果和启动检查数据；`compatibility.json` 保存检测方式及地址等诊断信息。安装失败时，DLL、地址映射、诊断文件和安装记录一起回滚；卸载只移除与本工具记录匹配的地址映射。

指令签名允许外部相对调用、RIP 相对寻址及 PE 重定位产生的地址差异，同时检查指令、常量、内部跳转和直接调用目标。自解包的可写可执行区在安装时检查磁盘代码，启动时不把其解包后的内存与密文直接比较。

## 0.1.4 改动说明

去掉热议度中的中文后缀，改为纯数字。补入原版的装饰上限和记录中的全部条件奖励；组合部件使用游戏原生的 `MaxBuzz` 函数。保留原版对代理展品和多展品容器的区别处理。计算不创建预览实体，不修改本馆库存或存档。真实取出后，另调用原版 `CalculateMaxBuzz` 并写入日志，便于核对特殊类型。

自动检查覆盖原版部件函数的缓冲区布局、64 位 ID、长度边界、整数显示与原有引用／外观路由；它们不能代替实机验证。

补上目录的基础热议度，并明确标注“基础”。品质加值读取本馆当前的 `LevelState.Config.ExhibitQualityBuzz`，不硬编码倍率；如果配置尚不可用，则保留展品定义中的基础数值并在日志标记 `quality_config=0`。目录计算只读取定义和配置，不生成预览实物，不改写存档。

## 0.1.1 修复说明

0.1.0 调用 IL2CPP 引用字段写入接口时多取了一层地址，导致托管字段保存了原生栈地址。仓库分类筛选器随后进行接口调用时访问无效类型信息，发生访问冲突。0.1.1 改为 `il2cpp_field_set_value_object`，直接传入托管对象，并增加引用身份读回校验。

该问题发生于虚拟列表筛选阶段。崩溃日志中尚无实物生成调用。
